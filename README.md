# 🏆 ATHLETIX — Gear Up. Game On.

A premium sports e-commerce website built with Next.js, TypeScript, and Tailwind CSS.

## Features

- **Home Page**: Hero section, featured categories, trending products, deals banner, brand showcase, testimonials, newsletter signup
- **Shop Page**: Full product catalog with filters (category, sport, brand, price range), sorting, and responsive grid
- **Product Detail Page**: Image gallery, size/color selectors, quantity picker, reviews, related products
- **Cart Page**: Item management, promo code support, order summary
- **Checkout Page**: Multi-step checkout (shipping, payment, review)
- **Additional Pages**: About Us, Contact, FAQ/Help Center, Account, 404

## Tech Stack

- **Framework**: Next.js 16 (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS 4
- **State Management**: React Context (Cart)

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the site.

## Design System

- **Primary**: `#0A0A0A` (Black)
- **Accent Orange**: `#FF5722` (Energy & Action)
- **Accent Blue**: `#2196F3` (Trust & Sport)
- **Accent Green**: `#00E676` (Success)
- **Typography**: Oswald (headings), Inter (body), DM Sans (prices)
